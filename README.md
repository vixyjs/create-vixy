# create-vixy

Scaffolding tool for creating Vixy projects.

## Usage

With Bun:
```bash
bun create vixy
```

With npm:
```bash
npm create vixy
```

With pnpm:
```bash
pnpm create vixy
```

With Yarn:
```bash
yarn create vixy
```

## What it does

This tool will:
- Prompt you for a project name
- Create a new directory with that name
- Generate a basic Vixy project structure
